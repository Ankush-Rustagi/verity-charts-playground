# Verity Charts Playground

A runnable Storybook that mirrors every customer-facing analytics chart shape in Command, with fake data and source backlinks. Visual companion to:

- `documentation/20-core-projects/ai-in-command/ai-platform-strategy/09-command-chart-inventory.md` (where every chart lives).
- `documentation/20-core-projects/ai-in-command/ai-platform-strategy/10-highcharts-feature-audit.md` (which Highcharts features the Verity primitive set has to cover).

## Using the three sections together

A useful pattern for design review:

1. Open a **01 Highcharts** story (e.g., Intercoms Dashboard) to see what production looks like today.
2. Open the matching **03 Verity Primitives** story (e.g., ColumnChart) in another tab.
3. Compare: the production story shows raw Highcharts options; the primitive story shows the same chart driven by structured props with the Controls panel.
4. The primitive story's "Production sources this primitive covers" table tells you which other production surfaces collapse into this primitive.

This is the workflow the playground is designed for.

## How to run

```bash
cd documentation/17-ux-design/verity-charts-playground
npm install
npm run storybook
```

Storybook opens on `http://localhost:6006`. Hot reload is on; any edit to a `*.stories.tsx` re-renders.

## How to add a new story

1. Pick the library group (`01-highcharts/` or `02-visx/`), then the subfolder by chart type.
2. Copy the closest existing `*.stories.tsx` as a template.
3. Update the chart options or visx setup to match your target.
4. Set `parameters.docs.description.component` to a paragraph that includes: what it shows, the production source path in `Verkada-Web`, and the Verity primitive target from the audit.
5. Use seeded fake data from `src/utils/fakeData.ts`.
